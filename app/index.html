How the poster is built

One photo becomes four views: a hero portrait plus wide, detail and sky crops of the same photo. The title strip is a skyline drawn in code — sun, scanline gaps, lit windows, palms — from a single fixed seed. The colour grade is computed per pixel. Nothing is uploaded; the photo never leaves this machine.
